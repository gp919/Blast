# 작업 노트

이슈 하나가 끝날 때마다 남기는 기록입니다. 두 가지가 들어갑니다.

1. **코드 리뷰 결과** — 지적된 것, 고친 것, 미룬 것
2. **Unity 개념 대응** — 그 작업에서 처음 쓴 Unity 및 C# 기능을 C++ 과 자체 엔진
   개념에 대응시킨 설명
3. **스크립트 파일별 설명** — 만들거나 고친 `.cs` 파일이 왜 따로 존재하는가.
   데이터가 파일들을 지나가는 경로부터 그리고 그 순서로 설명합니다

`docs/ai-collab-log.md` 와 역할이 다릅니다. 그쪽은 **AI 출력이 틀렸던 것**만 모으는
포트폴리오용 기록이고, 이쪽은 **작업자가 나중에 다시 읽기 위한** 기록입니다.
리뷰에서 나온 지적 대부분은 AI 오류가 아니므로 여기에만 남습니다.

작성 시점과 절차는 `docs/feature-closeout.md` 참조.

## 파일 이름

```
issue-<번호 두 자리>-<짧은-영문-설명>.md
```

브랜치 이름과 같은 설명을 씁니다. 나중에 커밋 이력과 대조하기 쉽습니다.
